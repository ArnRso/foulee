## Installation

1. Téléchargez **`Foulee-….dmg`** ci-dessous, ouvrez-le et glissez **Foulée** dans le dossier **Applications**.
2. Lancez Foulée. L'app n'étant pas notarisée par Apple, macOS la bloque la première fois :
   ouvrez **Réglages Système › Confidentialité et sécurité** et cliquez sur **Ouvrir quand même**.
   Ou, dans le Terminal : `xattr -dr com.apple.quarantine /Applications/Foulee.app`
3. Foulée apparaît dans la barre des menus (icône de marcheur). Acceptez l'autorisation Bluetooth.
   Après une mise à jour, macOS peut redemander cette autorisation.
4. Fermez l'appli du fabricant sur votre téléphone : le tapis n'accepte qu'une connexion à la fois.

Les versions suivantes s'installent depuis Foulée (mise à jour automatique, ou menu › Rechercher les mises à jour…).

Configuration requise : macOS 15 ou plus récent, Mac Apple Silicon ou Intel, tapis compatible
Bluetooth FTMS (Fitness Machine Service).
